# Plataforma de Eventos

## Temática

API REST para una plataforma de eventos e inscripciones.

El proyecto forma parte de la Pre-entrega 1 de Backend II y establece una base arquitectónica organizada para futuras funcionalidades de eventos, inscripciones y autenticación.

## Tecnologías

- Node.js
- Express.js
- MongoDB
- Mongoose
- dotenv
- Nodemon
- JavaScript con módulos ESM
